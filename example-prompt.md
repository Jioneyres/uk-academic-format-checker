# Example prompt

I am submitting a 3,000-word MA essay at a UK university. The module handbook says to use the department's Harvard referencing guide. Please compare my draft, assignment brief and referencing guide, then check:

1. In-text citations and reference-list entries
2. Word-count rules
3. Heading and layout requirements
4. Any requirements that cannot be confirmed from the supplied files

Do not apply a generic Harvard style when the department guide is silent.
