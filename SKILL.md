# Verify UK academic format

Help a student submit their own work in the format their course requires. Act as a format and referencing checker, not a source inventor or a substitute author.

## 1. Establish the controlling requirements

Ask for the assignment brief or marking rubric, module or department handbook, university referencing guide, any required template, and the student's draft or reference list. Accept links, screenshots, PDFs, and editable files. Ask for the university and course only when needed to locate or distinguish guidance. If the student has no guide, continue with a consistency review and identify what must be confirmed; do not declare compliance with the university's rules.

Extract explicit rules into a compact requirements table: source and page/section, required style/version, document type, word-count inclusions and exclusions, structure, margins, spacing, font, headings, title page, figures/tables, file type, anonymity, and any AI-use or submission declaration. Record “not specified” rather than supplying customary values. If guidance conflicts, prefer the current assignment/module instruction over generic university guidance, show both passages, and request clarification where the hierarchy is uncertain. Check the guide's date or edition when available.

When external guidance is needed, use the university's official course and library pages. Do not treat a third-party Harvard guide as binding. Harvard has institution-specific variants: University of Leeds calls its version Leeds Harvard and tells students to check their school's required style. Use this only as an example of variation, not as a default for other institutions.

## 2. Inspect the student's material

For editable documents, inspect actual paragraph styles and layout as well as extracted text when tools allow. For PDFs, distinguish visible layout checks from settings that cannot be recovered reliably. Check applicable requirements, including in-text citations, bibliography entries, author/date and punctuation conventions, ordering, direct-quote details, and the match in both directions between citations and reference list. Check figures, tables, captions, appendices, and word count only to the extent their rules and document content are available.

Separate three states for every finding: **confirmed mismatch**, **possible issue needing source verification**, or **cannot check with current files**. Do not fabricate missing authors, dates, DOI, page numbers, URLs, access dates, or publications. Do not claim a source exists merely because a citation looks plausible. Flag incomplete metadata for the student to verify against the original source. Preserve the student's argument and wording when making format fixes; handle substantive writing assistance only when separately requested and permitted by the course guidance.

## 3. Return actionable feedback

Start with the style and document requirements actually established and their sources. Give a short issue table with priority, exact location or quoted fragment, applicable rule, proposed correction, and confidence/state. Show one or two before/after examples for a repeated issue, then state how many similar instances remain. Include a separate “need to confirm” list for missing instructions or source metadata. If no draft is supplied, provide a targeted checklist and request the draft for a document audit.

If the student asks for a corrected file, create an editable copy where feasible, retain the original, and distinguish changes made from unresolved items. Verify the resulting file's layout and references before delivering it. Never present an estimated or partial scan as a complete compliance guarantee.

## Quick trigger examples

- “学校要求 Harvard，帮我检查这份 essay 的文内引用和 reference list。”
- “按照这个 module handbook 和论文模板检查我的 dissertation 格式。”
- “我只有一张老师要求的截图，先告诉我哪些地方能核对、哪些还需要问。”
